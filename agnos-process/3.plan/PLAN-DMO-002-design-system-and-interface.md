# PLAN-DMO-002: The Demo's Design System and Interface, Folded Back into its Scenario

## Overview
On 2026-10-24 a sub-agent added to the demo, directly in its git history, a design system and a web interface of the
product, with a UX designer `rob-ux` (sessions DSN and WEB, 28 commits). The scenario of the `agnos-demo` skill does not
hold them, so the next `build` would erase them. This plan folds them back into the scenario (RQ-DMO-022, DEC-DMO-007),

and rebuilds the demo, which then also gets the current toolkit (the History tab, the tooltips) and passes RQ-DMO-002
and RQ-DMO-008 again.
